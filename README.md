# Bending Springback Validation System v1.0 by Ramu Gopal

A validation-first engineering system for sheet-metal bending springback review.

This Windows desktop application helps engineers review bending springback behavior using rule-based calculations, practical engineering checks, validation status, and optional AI-assisted explanation.

---

## Overview

**Bending Springback Validation System v1.0** is designed to support sheet-metal bending review by combining calculation, validation, and engineering explanation in one interface.

Instead of only showing numeric results, the system checks practical engineering conditions such as:

- Bend radius to thickness ratio
- Yield strength to modulus ratio
- Springback risk level
- Recommended forming angle
- Tooling conditions such as V-die opening and punch radius
- Process-based validation for bending method

The goal is to help engineers quickly understand whether the bending setup is reasonable, needs review, or may require correction before manufacturing.

---

## Key Features

- Material selection for common sheet-metal materials
- Metric and Imperial unit support
- Geometry input for sheet thickness, bend radius, bend angle, and target angle
- Material property inputs for yield strength and elastic modulus
- Process setup for bending method, V-die opening, and punch radius
- Rule-based springback estimation
- Validation status with PASS / WARNING result
- Risk level indication
- Engineering check summary
- Result summary for documentation
- Optional AI Assist for explanation
- CSV material loading support
- Export report option
- Copy-to-clipboard support for engineering outputs
- Help window for basic usage guidance
